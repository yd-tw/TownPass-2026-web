# TownPass 2026 Web

TownPass App 可透過 WebView 開啟的即時論壇前端原型。`/chat` 顯示自己的聊天列表，`/forum` 顯示討論串；底部導覽或左右滑動可切換，網址會同步更新。舊入口 `/` 會導向 `/chat`。點選聊天列表中的問題或任一討論串，都會進入同一套 LINE 風格聊天室。

## 本機執行

```bash
npm ci
npm run dev
```

開啟 `http://localhost:3000/chat`。`/new`（或舊入口 `/?mode=ask`）直接開啟「我要發問」的新問題聊天室，App 的問題回報會開啟 `/new?source=app-report` 並帶入截圖；使用 `/chat?demo=mock` 或 `/forum?demo=mock` 可在不連後端時檢查示範資料。

## 目前功能

- 提問只輸入內容，不需標題或分類代碼；後端決定固定標籤，手動標籤可在問題選單新增或移除。
- 聊天頁列出自己的問題，沒有問題時可直接發問；討論串頁可搜尋、查看固定與手動標籤、留言數與附近通知圖示。
- 討論串和自己的問題共用 LINE 風格聊天室，可文字回覆、拍照、選擇圖片、傳送影片及錄製語音。
- 提問畫面的「…」可開關附近通知，預設開啟；開啟時會取得位置，關閉時不傳送位置欄位。
- 提問者可在聊天室將自己的問題標記為已完成；每則留言都可點讚，再點一次可取消。

預設連線後端；示範模式的資料會在重新整理後重置。聊天室直接解決與對自己的留言按讚依照 [`api-spec.md`](./api-spec.md) 的契約實作。

版面設計支援 200% 顯示比例的窄視窗。
