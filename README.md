# TownPass 2026 Web

TownPass App 可透過 WebView 開啟的即時論壇前端原型。首頁 `/` 提供原本的主頁、自己的聊天列表，以及討論串三個頁面；底部導覽或左右滑動可切換。點選聊天列表中的問題或任一討論串，都會進入同一套 LINE 風格聊天室。`/chat` 保留原有的獨立聊天示範。

## 本機執行

```bash
npm ci
npm run dev
```

開啟 `http://localhost:3000`。App 可使用 `/?mode=ask` 直接開啟提問畫面；使用 `/?demo=mock` 可在不連後端時檢查示範資料。

## 目前功能

- 提問只輸入內容，不需標題；後端自動分類，自訂標籤由後端回傳。
- 主頁提供個人資訊、問題統計與提問入口；聊天頁列出自己的問題；討論串頁可搜尋、查看標籤、留言數與附近通知圖示。
- 討論串和自己的問題共用 LINE 風格聊天室，可文字回覆、拍照、選擇圖片、傳送影片及錄製語音。
- 提問畫面的「…」可開關附近通知，預設開啟；開啟時會取得位置，關閉時不傳送位置欄位。
- 提問者可在聊天室將自己的問題標記為已完成；每則留言都可點讚，再點一次可取消。

預設連線後端；示範模式的資料會在重新整理後重置。聊天室直接解決與對自己的留言按讚依照 [`api-spec.md`](./api-spec.md) 的契約實作。

版面已在 200% 顯示比例的窄視窗檢查主頁、聊天、討論串與聊天室，沒有水平溢出。
